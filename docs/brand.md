# Keybook visual identity

The selected mark is a compact plum reference book with a cream bookmark and blue and orange index tabs. It was generated as a raster concept with MiniSub's `gpt-image-2` image endpoint and chosen by the user after comparing three directions at small sizes on light and dark surroundings.

The original 1254 × 1254 PNG is `design/keybook-icon-source.png`, and its exact generation prompt is `design/keybook-icon-prompt.txt`. Both published PNGs are resized from that source, with transparency retained. The source is a flattened raster image, not an editable vector or an Apple Icon Composer document.

Directory logo: `plugins/keybook/assets/logo.png` (512 × 512). Composer icon: `plugins/keybook/assets/icon.png` (128 × 128). Brand color: `#5B2552`.
